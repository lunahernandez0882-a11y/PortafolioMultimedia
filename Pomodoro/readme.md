# 🍅 Pomodoro

Una interfaz web de un temporizador **Pomodoro**, diseñada con una estética amigable inspirada en un tomate y elementos naturales.

## ✨ Características

* ⏱️ Temporizador de enfoque de 25 minutos.
* 🌿 Modo de descanso.
* ▶️ Botón para iniciar y pausar el temporizador.
* 🔄 Opción para reiniciar el temporizador.
* ⏭️ Opción para saltar al siguiente periodo.
* 📊 Indicador circular de progreso.
* 🎨 Interfaz con colores inspirados en tomates y hojas.
* 📱 Diseño tipo aplicación móvil.

## 🛠️ Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript
* SVG
* Google Fonts

## 🚀 Uso

1. Clona o descarga el repositorio.
2. Abre el archivo `index.html` en tu navegador.
3. Presiona **Iniciar** para comenzar el temporizador.
4. Utiliza **Reiniciar** para volver al inicio o **Saltar** para cambiar de periodo.

## 🎯 Objetivo

Crear una interfaz sencilla, visualmente agradable y funcional para aplicar la técnica **Pomodoro**, facilitando periodos de concentración y descanso.
